### Conlang Creator

## Setup
Enter whatever python venv you want to use and then install requirements with: 
```
pip3 install -r requirements.txt
```

## Run
Enter your venv and then run with:
```
streamlit run main.py
```

## Config Editing
Streamlit doesn't have a convenient way of editing JSON, so for now, if you want to get into the nitty gritty of the permutation configs, the way to do that is just by editing the JSON by hand.
